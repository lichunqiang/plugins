# Mayoi plugins

The index of plugins for [Mayoi](https://github.com/sorrycc/Mayoi). The Plugins page and `mayoi plugin search` read `index.json`.

To list a plugin, add an entry to `index.json` by pull request:

```json
{ "name": "word-stats", "description": "Words of the selection", "author": "Ann", "repository": "https://github.com/me/word-stats", "tags": ["text"] }
```
